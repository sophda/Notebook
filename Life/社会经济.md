
# 经济指标

## 物价
### PCE指数/CPI指数
PCE物价指数，全称**个人消费支出价格指数**，是衡量消费者为商品和服务支付价格变化的核心指标
CPI:消费者物价指数

| 对比维度     | **PCE物价指数**                                                                                                                                                                                                                              | **CPI（消费者物价指数）**                                                                                                                                                                                                              |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **统计范围** | 覆盖**所有**消费者支出，包括农村家庭，以及由第三方（如雇主、政府医保）代为支付的医疗费用[](https://www.clevelandfed.org/-/media/project/clevelandfedtenant/clevelandfedsite/Center-for-Inflation-Research/Inflation-101/Infographics/Infographic-on-Inflation_CPI-vs-PCE.pdf#1#1)。 | 仅限**城市家庭**的**自付**支出，不包括由医保等第三方支付的费用[](https://www.clevelandfed.org/-/media/project/clevelandfedtenant/clevelandfedsite/Center-for-Inflation-Research/Inflation-101/Infographics/Infographic-on-Inflation_CPI-vs-PCE.pdf#1#1)。 |
| **权重调整** | 权重**每月更新**，能更快捕捉消费者因价格变化而调整消费结构的行为[](https://www.clevelandfed.org/-/media/project/clevelandfedtenant/clevelandfedsite/Center-for-Inflation-Research/Inflation-101/Infographics/Infographic-on-Inflation_CPI-vs-PCE.pdf#1#1)。             | 权重**每年更新**，对消费模式变化的反应相对滞后[](https://www.clevelandfed.org/-/media/project/clevelandfedtenant/clevelandfedsite/Center-for-Inflation-Research/Inflation-101/Infographics/Infographic-on-Inflation_CPI-vs-PCE.pdf#1#1)。           |
| **权重差异** | **医疗保健**的权重更高，**住房**的权重相对较低[](https://www.federalreserve.gov/newsevents/speech/files/jefferson20230227a.pdf#2#1)。                                                                                                                        | **住房**的权重显著更高（约为PCE的两倍），医疗保健权重较低                                                                                                                                                                                              |
| **长期趋势** | 涨幅通常**低于CPI**。自2000年以来，CPI年通胀率平均比PCE高出约**0.39个百分点**。                                                                                                                                                                                     | 由于权重更新慢，且住房权重高，其读数通常更高，对市场短期情绪的影响也往往更大                                                                                                                                                                                        |


# 美国经济体系

## 美联储

双重使命：最大就业+物价稳定
美联储将长期通胀目标定义为：以PCE物价指数同比2%为长期目标

### 资产负债调整

QT&QE

QE: quantitative easing，量化宽松
即美联储买资产、创造准备金，比如：
```
Fed：
资产：
+1000亿美元国债

负债：
+1000亿美元银行准备金
```

- 于是银行体系里的准备金增加；
- 同时美联储买债，导致债券价格上升，债券收益率下降
---
QT：quantitative tightening，量化紧缩
跟QE是反过来的，即卖出资产，资产和负债都缩小

### “银行的银行”

 >对于普通人来说，将存款存入商业银行，
 
对于商业银行自己来说，他们有自己的”央行账户“，将钱存入美联储
银行在美联储持有**准备金（Reserve Balances）**
```
你的银行存款
属于商业银行负债

银行的准备金
属于美联储负债
```
---

**同时美联储同时扮演最后贷款人的角色**

比如某银行突然出现的挤兑问题，银行有200亿资产（长期贷款/债券），但是突然有客户提款50亿，但是银行并没有足够的**现金**

这时候银行只能去变卖自己的资产，这种急性抛售会导致债券价格暴跌，其他银行也被迫卖，导致金融系统践踏。

但是美联储可以通过discount window 贴现窗口提供流动性。
### 联邦基金利率
 > 先看几个概念：
 > 1. FOMC：美联储内部决定货币政策的委员会
 > 2. interest on reserve balances（IORB）:作用是美联储给银行存在美联储账户里的**准备金**支付多少利息。
 > 3. Federal Funds Target Range：FOMC设定的目标区间，例如

**Federal funds rate**：这个是美国银行体系里的金融机构之间进行超短期资金拆借的基准利率。**这个是金融机构隔夜借贷准备金时，实际成交出来的利率，是市场行为决定的，不是人为决定的，因此需要通过政策和金融工具引导市场行为**

---
IORB的作用是美联储用来把基金利率引导到FOMC的目标区间内。
美国联邦基金利率底层影响的是隔夜银行准备金的价格，也就是商业银行存在美联储的准备金年化利率升高（加息）以及降低（降息），会影响商业银行之间借准备金的意愿。

---
于是乎，就有了经典的传到链条：
- **加息时： **借钱 ↓ → 投资 ↓ → 消费 ↓ → 经济活动降温 → 通胀压力下降**
- **降息时：借钱 ↑ → 企业投资 ↑ → 居民消费 ↑ → 经济活动增强**
